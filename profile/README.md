Welcome to the official GitHub organization for Finger Trader. We build financial technology infrastructure, trading connectivity, and developer tools for modern financial markets.

Our mission is to make financial technology more accessible, interoperable, and reliable through robust APIs, scalable infrastructure, and developer-friendly software.

## Developer ecosystem

Our products and projects focus on:

- **Trading APIs** — Programmatic access to supported market data, account information, order management, and trading connectivity.
- **Python SDK** — Tools for integrating with Finger Trader services and building algorithmic trading workflows.
- **Market data infrastructure** — Services for accessing, processing, and distributing data across supported asset classes.
- **Algorithmic trading** — Developer tools for strategy development, quantitative research, and supported automated trading integrations.
- **Brokerage technology** — Infrastructure for brokerage integrations, order management systems (OMS), and supported execution and clearing providers.

Feature availability depends on the product, integration environment, and release version.

## Open-source projects

### [Finger Trader Python SDK](https://github.com/FingerTrader/fingertrader-python-sdk)

The official Python SDK provides programmatic access to supported Finger Trader APIs and services. See the repository for current release status, documentation, supported functionality, and integration requirements.

Capabilities include:

- Authentication and API connectivity
- Market data and historical price information
- Account balances and positions
- Order submission and management interfaces
- WebSocket subscriptions
- Error handling and API response models
- Developer integration examples

## Security and responsible development

Security, reliability, and responsible engineering are fundamental to our work. We encourage secure API authentication, responsible credential management, protection of sensitive financial information, supply-chain security, responsible vulnerability disclosure, and transparent documentation and version management.

Follow the security policy in each repository for vulnerability reporting instructions. Do not post credentials, API keys, account information, or security vulnerabilities in public issues or discussions.
