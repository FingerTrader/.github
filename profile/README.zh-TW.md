歡迎來到 Finger Trader 官方 GitHub 組織。我們為現代金融市場打造金融科技基礎建設、交易連線方案與開發者工具。

我們的使命是透過穩健的 API、可擴充的基礎建設與開發者友善的軟體，讓金融科技更易於採用、更具互通性且值得信賴。

## 開發者生態系

我們的產品與專案聚焦於以下領域：

- **交易 API** — 以程式介接支援的市場資料、帳戶資訊、訂單管理與交易連線。
- **Python SDK** — 協助開發者串接 Finger Trader 服務並建置程式化交易流程的工具。
- **市場資料基礎建設** — 用於取得、處理及分發支援資產類別資料的服務。
- **程式化交易** — 支援策略開發、量化研究及已支援自動交易整合的開發者工具。
- **券商科技** — 支援券商整合、訂單管理系統（OMS），以及與支援的交易執行和結算服務商連線的金融科技基礎建設。

功能是否提供，依產品、整合環境及發布版本而異。

## 開源專案

### [Finger Trader Python SDK](https://github.com/FingerTrader/fingertrader-python-sdk)

官方 Python SDK 可用於程式介接支援的 Finger Trader API 與服務。最新發布狀態、文件、支援功能及整合需求，請以該專案儲存庫為準。

主要功能包括：

- 身分驗證與 API 連線
- 市場資料與歷史價格資訊
- 帳戶餘額與持倉
- 訂單送出與管理介面
- WebSocket 訂閱
- 錯誤處理與 API 回應模型
- 開發者整合範例
