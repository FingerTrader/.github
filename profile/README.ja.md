Finger Trader の公式 GitHub 組織へようこそ。私たちは、現代の金融市場に向けた金融テクノロジー基盤、取引接続ソリューション、開発者向けツールを開発しています。

堅牢な API、拡張性の高いインフラ、開発者にとって使いやすいソフトウェアを通じて、金融テクノロジーの利便性、相互運用性、信頼性を高めることを目指しています。

## 開発者向けエコシステム

当社の製品とプロジェクトは、次の分野を中心に展開しています。

- **取引 API** — 対応するマーケットデータ、口座情報、注文管理、取引接続をプログラムから利用するための API。
- **Python SDK** — Finger Trader のサービスと連携し、アルゴリズム取引のワークフローを構築するための開発者向けツール。
- **マーケットデータ基盤** — 対応する資産クラスのデータを取得、処理、配信するためのサービス。
- **アルゴリズム取引** — 戦略開発、クオンツリサーチ、対応する自動取引連携を支援する開発者向けツール。
- **ブローカーテクノロジー** — ブローカー連携、注文管理システム（OMS）、対応する執行・清算プロバイダーとの接続を支える基盤。

機能の提供状況は、製品、連携環境、リリースバージョンによって異なります。

## オープンソースプロジェクト

### [Finger Trader Python SDK](https://github.com/FingerTrader/fingertrader-python-sdk)

公式 Python SDK を通じて、対応する Finger Trader API とサービスをプログラムから利用できます。最新のリリース状況、ドキュメント、対応機能、連携要件はリポジトリをご確認ください。

主な機能：

- 認証と API 接続
- マーケットデータと過去価格データ
- 口座残高とポジション
- 注文の発注・管理インターフェース
- WebSocket サブスクリプション
- エラー処理と API レスポンスモデル
- 開発者向け連携サンプル
